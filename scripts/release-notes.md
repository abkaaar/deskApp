## Foodpos 1.0.0

Windows NSIS installer for Foodpos (restaurant POS and operations).

### Install
1. Download Foodpos-1.0.0-setup.exe
2. Run the installer (SmartScreen may warn on unsigned builds - More info, then Run anyway)
3. Launch Foodpos from the Start menu

### Notes
- Requires a Foodma premium restaurant account
- Staff sign-in: email + access code from the vendor portal
